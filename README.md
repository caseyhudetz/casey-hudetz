# Casey Hudetz Portfolio

A modern, minimal portfolio website for Casey Hudetz — product design leader, speaker, teacher and award-winning filmmaker.

**Live site:** caseyhudetz.com

## Overview

This is a single-page portfolio website built for GitHub Pages. It showcases Casey's work in product design, AI strategy, documentary filmmaking and international speaking engagements.

## Features

- Refined minimalist design with editorial sensibility
- Video modal for viewing work samples directly on the site
- Responsive layout optimized for all devices
- Dark mode support based on system preference
- Fast performance with lazy loading and minimal dependencies
- Accessible semantic HTML, keyboard navigation and ARIA support

## Tech Stack

- Pure HTML, CSS and JavaScript
- Google Fonts
- Vimeo and YouTube embeds

## Development

No build tools required. Open `index.html` directly or run a small local server:

```bash
python -m http.server 8000
```

## Deployment

The site is configured for GitHub Pages with a custom domain. The `CNAME` file points to `caseyhudetz.com`.
